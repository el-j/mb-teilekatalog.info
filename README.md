# MB Teilekatalog

> **Community-betriebener Ersatzteilkatalog für klassische Mercedes-Benz-Fahrzeuge**

A fast, modern, statically hosted replacement for the original mb-teilekatalog.info website.
Built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Features

- 🚀 Blazing-fast static site – no database, no server
- 🚐 Starting with the Mercedes-Benz **T1 "Bremer"** (W601/W602, 1977–1995)
- 📋 Parts catalog with part numbers, German & English descriptions
- 🔍 Collapsible part groups for easy navigation
- 🌍 Bilingual (DE/EN)
- 📖 Open data under **CC BY-SA 4.0**

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
